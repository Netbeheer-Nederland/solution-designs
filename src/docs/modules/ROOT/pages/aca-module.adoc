== Dataset

Voor de informatiebehoefte van Buurtnet worden vier dataproducten vanuit de
_NBNL Profile Group_ (her)gebruikt:

* *Equipment* (EQ): connectiviteit voor het elektriciteitsnet, definitie van
  netfuncties voor de overige dataproducten;
* *Operation* (OP): belasting van transformatoren en andere netfuncties;
* *GeoLocation* (GL): locatie van aansluitingen in het elektriciteitsnet;
* *Topology* (TP): koppeling tussen overdrachtspunt en transformator en
  nethierarchie;
* *Asset* (AS): netuitbreiding en congestierapport.
