= Automated Congestion Assessment (ACA)

The *DSO-TSO Congestion Data Exchange* outlines the framework for data exchange
between Distribution System Operators (DSOs) and Transmission System Operator
(TSO) for _congestion management study_ purposes. This initiative aims to
enhance the accuracy and efficiency of energy data management, ensuring
seamless integration and communication between system operators.

This document details various aspects of data exchange, including load
profiles, and prognosis logic. It emphasizes the importance of adhering to
standardized formats for time series data, which ensures consistency and
reliability in data delivery for all parties involved. The document also
highlights the roles and responsibilities of different stakeholders involved in
the project, providing a clear approach for implementation and approval
processes.

This document is prepared in English in order to facilitate software
development and ensure the broadest possible understanding and compatibility
across teams and stakeholders.
