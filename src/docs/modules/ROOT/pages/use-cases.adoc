= Use Cases NBNL Profile Group

== Reikwijdte

Dit document beschrijft de use cases en invulling van de
https://modellen.netbeheernederland.nl/data-products/information-models/nbnl-profile-group.html[NBNL
Profile Group]. De _NBNL Profile Group_ bestaat uit de volgende dataproducten
(_profiles_):

* _Equipment_ (EQ): defines the electrical equipment in the network model,
  including their technical characteristics and relationships
* _Asset_ (AS): describes the physical assets owned or managed by the utility,
  including their identity, lifecycle, and management information
* _Operation_ (OP): captures the real-time operational state and control
  information of the power system used for monitoring and running the network
* _Geographical Location_ (GL): provides the geographic position and spatial
  representation of network assets and equipment on maps or geographic systems
* _Topology_ (TP): represents an abstraction of the current electrical
  connectivity of the network for a specific use case

== Onderwerpen

Onderwerpen zijn specifieke verzamelingen van functionaliteit. Elk onderwerp is
netvlakagnostisch, i.e. van toepassing op elk spanningsniveau. Ook wordt enige
kennis van de bijbehorende use cases verwacht: voor Buurtnet wordt b.v. een
belastingprofiel in kwartierwaarden voor 24h en 48h vooruit. Voor het
Aansluitoffensief is dit profiel per uur, 10 jaar vooruit.

== Use cases

functionele eisen vanuit een werkgroep, voor een specifiek spanningsniveau.

hoeven, afhankelijk van gemaakte afspraken, niet alle CIM-classes
